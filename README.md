## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/indhiran08-coder/zerotozetta.git

# Navigate to project directory
cd zerotozetta

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
```
The optimized bundle will be generated in the `dist/` directory, ready for deployment on **Vercel**, **Netlify**, or **Cloudflare Pages**.

---

## 🌐 Deploying to Vercel / Netlify

### Deploy with Vercel (Recommended):
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your `zerotozetta` GitHub repository.
4. Framework Preset will be automatically detected as **Vite**.
5. Click **"Deploy"** — your site will be live on a custom `.vercel.app` domain in seconds!
